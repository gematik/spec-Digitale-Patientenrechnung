# Hinweis zu Artefakt-Versionen

| | |
| :--- | :--- |
| ![](Betriebskoordination_Gruen_gematik.svg) | **Hinweis:**Die Version eines einzelnen Artefakts kann von der Paketversion dieser Spezifikation abweichen. |

Die **Paketversion** kennzeichnet den Gesamtstand dieser Spezifikation. **Profile, Extensions, CodeSystems, ValueSets, CapabilityStatements, OperationDefinitions und SearchParameter** tragen darüber hinaus jeweils eine **eigene Version**.

Der Grund: Jedes Artefakt wird eigenständig versioniert. Mit einem neuen Release erhält ein Artefakt nur dann eine neue Version, wenn sich sein Inhalt gegenüber dem vorherigen Release tatsächlich geändert hat. Unveränderte Artefakte behalten ihre bisherige Version. Dadurch laufen die Artefakt-Versionen mit der Zeit auseinander und liegen in der Regel unterhalb der aktuellen Paketversion.

Für die Nutzung bedeutet das:

* Die **Paketversion** gibt das Gesamt-Release der Spezifikation an.
* Die **Version eines Artefakts** zeigt, mit welchem Release es zuletzt inhaltlich geändert wurde. Bleibt sie über mehrere Releases unverändert, wurde auch das Artefakt in dieser Zeit inhaltlich nicht geändert.

So lässt sich an der Version eines Artefakts unmittelbar ablesen, ob und wann es sich zuletzt geändert hat – unabhängig davon, wie oft die Spezifikation insgesamt veröffentlicht wurde.
